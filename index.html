ดึงราคาสด (ทดลอง)
⚠️ ใช้ endpoint สาธารณะที่ไม่เป็นทางการ ทำงานจากเบราว์เซอร์ของคุณโดยตรง อาจใช้ไม่ได้บ้างขึ้นกับเครือข่าย/เบราว์เซอร์ (ติด CORS) — หากไม่สำเร็จให้เลื่อนลงไปกรอกข้อมูลด้วยตนเองด้านล่างแทน ไม่ใช่ข้อมูลทางการจาก SET
ใส่ชื่อย่อหุ้นต่อท้ายด้วย .BK เช่น PTT.BK, AOT.BK, CPALL.BK — ดัชนี SET โดยรวมอาจไม่มีใน endpoint นี้
เช็คสถานะด้วยตนเอง
คัดหุ้น
ให้คะแนนหุ้นจาก 4 ปัจจัย: แนวโน้มราคา (35%) · โมเมนตัม RSI (15%) · ความแข็งแกร่งเทียบ SET (30%) · สภาพคล่อง (20%) — กรอกข้อมูลจริงของหุ้นที่สนใจจากโปรแกรมเทรดของคุณ
อันดับหุ้น
Backtest
ทดสอบกลยุทธ์เข้า-ออกกับข้อมูลราคาย้อนหลัง 2 ปี — ใส่ข้อมูลราคาจริงของหุ้นที่สนใจ หรือลองกับข้อมูลตัวอย่างก่อนเพื่อดูวิธีใช้งาน
รูปแบบ: Date,Open,High,Low,Close,Volume หนึ่งแถวต่อวัน (คัดลอกจาก SETTRADE, Investing.com, aomMONEY หรือไฟล์ที่ดาวน์โหลดจากโบรกเกอร์ได้) ควรมีข้อมูลอย่างน้อย ~500 วันทำการ (2 ปี) เพื่อความแม่นยำของเส้นค่าเฉลี่ยระยะยาว
คำนวณรวมค่าคอมมิชชัน+ค่าธรรมเนียม ~0.16% ต่อขา (ซื้อ/ขาย) ตามอัตราทั่วไปของโบรกเกอร์ในตลาด SET
คู่มือหลักการ
สรุปหลักการเลือกหุ้นและจังหวะเข้า-ออกที่ใช้ในเครื่องมือนี้
🎯 หลักการเลือกหุ้น (Stock Selection)
  • แนวโน้ม: ราคา > SMA50 > SMA200 (แนวโน้มขาขึ้นเต็มรูปแบบ) ได้คะแนนสูงสุด
  • ความแข็งแกร่งเทียบตลาด (Relative Strength): หุ้นที่ทำผลตอบแทนดีกว่าดัชนี SET ในช่วง 3 เดือนที่ผ่านมา มักมีแรงซื้อสถาบัน/ต่างชาติหนุนอยู่
  • สภาพคล่อง: เลือกหุ้นที่มีมูลค่าซื้อขายเฉลี่ยต่อวันสูงพอ (ปริมาณเทียบค่าเฉลี่ย 20 วัน > 1) เพื่อเข้า-ออกได้คล่องตัว ไม่ติดฟลอร์/ซิลลิ่ง
  • โมเมนตัม (RSI): RSI ราว 50-65 บ่งชี้แนวโน้มแข็งแรงแต่ยังไม่ overbought เกินไป
  • หลีกเลี่ยง: หุ้นที่ติด Cash Balance/SP, ฟรีโฟลตต่ำมาก หรือขาดทุนสะสมรุนแรงโดยไม่มีปัจจัยพื้นฐานรองรับ
📐 กลยุทธ์จังหวะเข้า-ออกที่ใช้
1) Golden Cross (SMA50/200) — ซื้อเมื่อ SMA50 ตัดขึ้นเหนือ SMA200 (สัญญาณเทรนด์ขาขึ้นระยะยาว) ขายเมื่อตัดลงกลับ (Death Cross) เหมาะกับหุ้นเทรนด์ชัดเจน แต่สัญญาณจะช้าและมีจำนวนไม้น้อย
2) EMA Pullback + RSI — ในหุ้นที่ราคาอยู่เหนือ EMA50 (เทรนด์ขึ้น) รอจังหวะ RSI ย่อตัวลงต่ำกว่า 40 แล้วดีดกลับขึ้น จึงเข้าซื้อ ขายเมื่อ RSI เกิน 70 หรือราคาหลุด EMA21 เหมาะกับการเข้าซื้อในจังหวะย่อของเทรนด์ขาขึ้น
3) Donchian Breakout + ATR Stop — ซื้อเมื่อราคาปิดทำจุดสูงสุดใหม่ในรอบ 20 วัน ตั้งจุดตัดขาดทุนแบบ Trailing Stop ที่ 2 เท่าของ ATR จากจุดสูงสุด เหมาะกับหุ้นที่กำลังทำสถิติใหม่ แต่มีอัตราชนะต่ำ (ชนะน้อยครั้งแต่ได้กำไรก้อนใหญ่เมื่อถูก)
4) RSI Mean Reversion — ซื้อเมื่อ RSI ต่ำกว่า 30 (oversold) และราคายังไม่หลุดแนวโน้มหลัก ขายเมื่อ RSI เกิน 60 เหมาะกับหุ้นที่แกว่งตัวในกรอบ (sideways) ไม่เหมาะกับหุ้นที่กำลังเป็นเทรนด์ขาลงรุนแรง
⚖️ การบริหารความเสี่ยง
  • เสี่ยงต่อไม้ไม่เกิน 1-2% ของพอร์ตทั้งหมด — คำนวณขนาดสถานะจาก (เงินทุน × %ความเสี่ยง) ÷ (ราคาซื้อ − ราคาตัดขาดทุน)
  • ตั้งจุดตัดขาดทุนทุกครั้งก่อนเข้าซื้อ เช่น ต่ำกว่าแนวรับ หรือ 1.5-2 เท่าของ ATR
  • อย่าถัวเฉลี่ยขาดทุนในหุ้นที่หลุดแนวโน้มขาขึ้นแล้ว
  • กระจายความเสี่ยงหลายหุ้น/หลายอุตสาหกรรม อย่ากระจุกในตัวเดียว
  • เทรดตามทิศทางของดัชนี SET โดยรวม — ตลาดขาลงรุนแรง ควรลดขนาดสถานะหรือถือเงินสด
🧪 ข้อจำกัดของเครื่องมือนี้
แท็บ "ตลาด" มีฟีเจอร์ดึงราคาสดแบบทดลอง ซึ่งใช้ endpoint สาธารณะที่ไม่เป็นทางการและทำงานจากเบราว์เซอร์ของคุณเอง จึงไม่รับประกันความเสถียร อาจใช้ไม่ได้ในบางเครือข่าย/เบราว์เซอร์ (ติดปัญหา CORS) และไม่ใช่ข้อมูลทางการจาก SET การ Backtest ที่แม่นยำจึงควรใช้ข้อมูลราคาย้อนหลังที่คุณนำเข้าเอง (CSV) จากแหล่งข้อมูลที่เชื่อถือได้ หรือใช้ชุดข้อมูลตัวอย่างที่จำลองขึ้นเพื่อสาธิตวิธีการทำงานของระบบเท่านั้น ผลลัพธ์จากข้อมูลจำลองไม่สะท้อนหุ้นจริงแต่อย่างใด
